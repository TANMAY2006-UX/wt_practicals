# MyProfile - MERN Stack Laboratory (Experiments 1-10)

Each folder is a separate experiment. Experiments build on each other,
and Experiment 10 is the final complete project.

## Prerequisites
- Node.js 18+ (https://nodejs.org)
- VS Code (https://code.visualstudio.com)
- MongoDB (needed from Experiment 7 onward):
  - Local: install MongoDB Community Server and run it on 127.0.0.1:27017
  - Or use MongoDB Atlas and put the connection string in a .env file as MONGO_URI

## How to run
1. Open the experiment folder in VS Code (File > Open Folder).
2. Open the integrated terminal (Ctrl + `).
3. Follow the "How to run" section in that experiment's README.

## Folder overview
| Folder | Topic |
|---|---|
| exp01-javascript-es6 | ES6, closures, destructuring (static HTML page) |
| exp02-typescript | Interfaces, classes, generics (TypeScript) |
| exp03-fetch-async | Fetch API, async/await, REST data |
| exp04-react-spa | React components, props, state, useEffect (Vite) |
| exp05-react-router-forms | React Router + forms (Vite) |
| exp06-express-api | Express REST API with CRUD and error handling |
| exp07-mongoose | MongoDB + Mongoose schema and CRUD |
| exp08-jwt-auth | bcrypt password hashing, JWT login, protected routes |
| exp09-mern-crud | Full MERN CRUD (React + Express + MongoDB) |
| exp10-capstone | Final MyProfile app with admin login and dashboard |
