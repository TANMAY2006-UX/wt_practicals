# Experiment 6 - Express REST API

## How to run (VS Code terminal)
```
npm install
npm start
```
Test in browser: http://localhost:5000/api/projects

Test POST/PUT/DELETE with the VS Code "Thunder Client" extension or Postman:
- POST   /api/projects       body: {"title":"...","description":"..."}
- PUT    /api/projects/:id   body: {"title":"...","description":"..."}
- DELETE /api/projects/:id
